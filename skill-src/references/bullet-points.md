# CV Bullet Point Rules

Use this structure for every rewritten bullet point:

> Action Verb + Task + Tool/Method + Result/Impact

## Examples by strength tier

**Weak:**
> Worked on data analysis project using Python.

**Better** (adds tool specificity and purpose):
> Analyzed customer behavior data using Python, Pandas, and SQL to identify purchasing
> patterns and generate insights for business decision-making.

**Stronger** (adds scale/quantification):
> Analyzed 50,000+ customer transaction records using Python, Pandas, and SQL, identifying
> purchasing patterns that supported customer segmentation and marketing recommendations.

The jump from "better" to "stronger" is almost always quantification — scale, percentage,
time saved, revenue impact, accuracy improvement. If the user doesn't have a real number,
don't invent one — instead push for scope language that's still truthful ("across X
data sources," "for a team of Y," "over Z months") rather than fabricated metrics.

## Strong action verbs

Built, Developed, Designed, Automated, Analyzed, Optimized, Implemented, Deployed, Cleaned,
Modeled, Visualized, Integrated, Evaluated, Improved, Presented, Collaborated, Engineered,
Streamlined, Refactored, Validated, Monitored, Tested, Documented.

## Phrases to eliminate

Helped with, Worked on, Responsible for, Involved in, Participated in, Learned about,
Assisted with, Did research on.

These phrases describe presence, not contribution. When you see one of these in a user's
draft, ask (or infer from context) what they actually *did* — the verb almost always reveals
that the original phrasing was hiding a stronger, more specific claim.

## Process for rewriting a user's bullet

1. Identify what they actually did (the real action) — strip out passive/vague framing.
2. Identify the tool or method used, if not already stated.
3. Identify any quantifiable outcome — ask the user if it's not provided, rather than guessing.
4. Reconstruct using Action Verb + Task + Tool/Method + Result/Impact.
5. Flag if the result/impact is still missing after rewriting — a bullet without impact is
   weaker even with a strong verb, and the user should know that gap remains.
